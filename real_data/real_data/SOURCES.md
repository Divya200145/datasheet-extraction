# Sources for the real PDFs I tried

The PDFs are the property of their publishers and are not included in this repository. Download them from the original sources below to reproduce `real_data/FINDINGS.md`.

| Document | Where I got it |
|---|---|
| INOXPA DIN-FOOD hygienic centrifugal pump, technical datasheet FT 01.110.33.01 (EN, ES, FR, RU) | INOXPA centrifugal pump downloads page: https://www.inoxpa.com/downloads/documents/pumps/centrifugal-pumps |
| KSB KWP-Bloc type series booklet | https://www.lenntech.com/data-sheets/KSB-KWP-bloc-EN-L.PDF |
| Goulds pump selection chart | https://www.lenntech.com/data-sheets/Goulds-Pumpselector-L.pdf |
| Alfa Laval centrifugal pump application data sheet (blank form) | https://www.fergusonindustrial.com/wp-content/uploads/2020/05/AlfaLaval_App_CentrifPump_DataSheet.pdf |
| Spirax Sarco "Controls and Instrumentation" brochures (SB-GCM-25, SPB1047-US) | Spirax Sarco control valves page: https://www.spiraxsarco.com/global/gb/products/control-systems/control-valves |
| FUNSD paper (not an equipment document) | https://arxiv.org/abs/1905.13538 |
| DocILE paper (not an equipment document) | https://arxiv.org/abs/2302.05658 |

Put the downloaded PDFs in any folder and run `python scripts/try_real_pdfs.py that_folder`.
